# Unemployment Analysis with Python

## 📌 Project Overview

This project analyzes unemployment trends in India using Python. The analysis focuses on regional unemployment patterns, monthly trends, and the impact of the COVID-19 pandemic using Exploratory Data Analysis (EDA).

## 🎯 Objective

- Analyze unemployment trends across Indian states.
- Compare unemployment rates before and after COVID-19.
- Visualize unemployment patterns using charts and graphs.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Project Features

- Data Loading and Inspection
- Data Cleaning
- Missing Value Handling
- Region-wise Average Unemployment Analysis
- Month-wise Trend Analysis
- Time-Series Analysis for Major States
- Top 10 States with Highest Unemployment
- Correlation Heatmap
- Pre-COVID vs Post-COVID Comparison

## 📈 Key Findings

- Tripura recorded the highest average unemployment rate.
- Unemployment peaked during April and May 2020 due to the COVID-19 lockdown.
- Delhi experienced the highest spike among the selected major states.
- The post-COVID unemployment rate was significantly higher than the pre-COVID period.

## 📂 Dataset

The dataset used is **"Unemployment in India"** from Kaggle.
